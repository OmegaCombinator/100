## Formalization

This is a complete Acorn wrapper proof of the fundamental theorem of arithmetic
for natural numbers. The statement says that every positive natural number has a
list of prime factors whose product is the number, and that any other prime list
with the same product is a permutation of that list.

The proof reuses the current standard-library theorems
`nat.nat_factorisation.prime_factorisation_exists` and
`nat.nat_factorisation.prime_factorisation_unique`.

The final public theorem is:

```acorn
theorem top100_080_fundamental_theorem_of_arithmetic(n: Nat) {
    Nat.1 <= n implies exists(factors: List[Nat]) {
        product[Nat](factors) = n and all_prime(factors) and
        forall(other: List[Nat]) {
            product[Nat](other) = n and all_prime(other) implies
            is_permutation[Nat](factors, other)
        }
    }
} by {
    if Nat.1 <= n {
        prime_factorisation_exists(n)
        let factors: List[Nat] satisfy {
            product[Nat](factors) = n and all_prime(factors)
        }
        forall(other: List[Nat]) {
            if product[Nat](other) = n and all_prime(other) {
                product[Nat](factors) = product[Nat](other)
                prime_factorisation_unique(factors, other)
                is_permutation[Nat](factors, other)
            }
        }
    }
}
```

## Interpretation

This matches the usual theorem that positive integers factor into primes and
that the factorisation is unique up to reordering.

The proof has been verified with Acorn.
