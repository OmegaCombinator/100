from int.int_base import Int
from nat.nat_base import Nat
from zmod import int_mod_rel, int_mod_rel_add_compatible, int_mod_rel_is_equivalence, int_read_mod3_step

theorem int_read_mod3_compatible(x: Int, y: Int, d: Int) {
    int_mod_rel(Nat.3, x, y) implies int_mod_rel(Nat.3, x.read(d), y.read(d))

    int_read_mod3_step(x, d)

## Interpretation

Together these staged lemmas show the one-step decimal recurrence needed for the divisibility-by-3 rule and prove that the read operation is compatible with congruence modulo 3. The next useful target is a lift from one decimal-read step to a list of digits.
