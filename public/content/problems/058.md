# #58 Formula for the Number of Combinations

Status: passed.

## Formalization

This is a complete Acorn proof of the standard factorial formula for binomial coefficients:

```acorn
k <= n implies n.binom(k) * k.factorial * (n - k).factorial = n.factorial
```

It reuses the current standard-library theorem `nat.nat_combo.choose_add`, which proves the same identity in the equivalent form for `a + b`.

## Acorn proof

```acorn
from nat.nat_base import Nat
from nat.nat_combo import choose_add

/// Freek Top 100 #58: formula for the number of combinations.
theorem top100_058_combinations_formula(n: Nat, k: Nat) {
    k <= n implies n.binom(k) * k.factorial * (n - k).factorial = n.factorial
} by {
    choose_add(k, n - k)
    k + (n - k) = n
}
```
