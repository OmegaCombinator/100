## Formalization

This is a complete Acorn proof of the Konigsberg bridges problem for the
classical seven-bridge graph. The public Top 100 wrapper states:

```acorn
theorem top100_054_konigsberg_bridges(steps: List[DirectedKonigsbergBridge]) {
    not directed_konigsberg_eulerian_trail(steps)
}
```

The proof models the four land masses and seven bridges directly. Each bridge
has two directed crossings, and a candidate Eulerian trail is a directed walk
whose underlying bridge count is exactly one for each of the seven bridges.

The proof derives the fixed incident counts of the four land masses from the
every-bridge-once condition: the counts are `3`, `3`, `5`, and `3`. It then
proves the standard endpoint parity obstruction for directed walks: every
non-endpoint land mass has an even incident count. Thus each of the four odd
land masses would have to be one of the two endpoints, which is impossible.

## Interpretation

This is the usual Eulerian-trail obstruction specialized to the Konigsberg
bridge graph. Since all four land masses have odd degree, there is no walk that
crosses each bridge exactly once.
