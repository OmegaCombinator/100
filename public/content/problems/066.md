# #66 Sum of a Geometric Series

Status: passed.

## Formalization

This is a complete Acorn wrapper proof for the finite geometric-series formula over rings. It uses the current official standard-library theorem `ring.geometric_sum`, whose statement proves:

```acorn
(a + -R.1) * sum(map(n.range, a.pow)) = a.pow(n) + -R.1
```

for any ring `R`, element `a : R`, and `n : Nat`. This is the multiplication form of the usual finite identity `(a - 1)(1 + a + ... + a^(n-1)) = a^n - 1`.

## Verification

- Verification: OK with Acorn `0.1.68`

## Acorn proof

```acorn
from list.list_base import map
from list.list_sum import sum
from nat.nat_base import Nat
from ring import Ring, geometric_sum

/// Freek Top 100 #66: the finite sum formula for a geometric series.
theorem top100_066_geometric_series[R: Ring](a: R, n: Nat) {
    (a + -R.1) * sum(map(n.range, a.pow)) = a.pow(n) + -R.1
} by {
    geometric_sum[R](a, n)
}
```
