## Formalization

This is a complete Acorn proof of Bezout's theorem for integer gcds. The core
identity states that the integer gcd of `a` and `b` is an integer linear
combination of them:

```acorn
theorem top100_060_bezout_identity(a: Int, b: Int) {
    exists(x: Int, y: Int) {
        a.gcd(b) = a * x + b * y
    }
}
```

The public Top 100 wrapper uses the same witness `d = a.gcd(b)` and matches the
HOL-style statement that there exists a nonnegative common divisor expressible
as an integer linear combination:

```acorn
theorem top100_060_bezouts_theorem(a: Int, b: Int) {
    exists(d: Int) {
        not d.is_negative and
        d.divides(a) and
        d.divides(b) and
        exists(x: Int, y: Int) {
            d = a * x + b * y
        }
    }
}
```

## Interpretation

This matches the standard Bezout identity: the gcd of two integers lies in the
integer span of those two integers, and it is a common divisor of both.
