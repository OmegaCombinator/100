## Formalization

This is a complete Acorn proof of the Schroeder-Bernstein theorem in function
form. The public Top 100 wrapper states that if there is an injection from `A`
to `B` and an injection from `B` to `A`, then there is a bijection from `A` to
`B`:

```acorn
theorem top100_025_schroeder_bernstein[A, B](f: A -> B, g: B -> A) {
    is_injective_fn(f) and is_injective_fn(g) implies exists(h: A -> B) {
        is_bijection_fn(h)
    }
}
```

The proof uses the standard chain construction. Starting from elements of `A`
that are not in the image of `g`, it closes under the step `a -> g(f(a))`. The
constructed bijection maps chain elements using `f`, and maps non-chain elements
using the unique inverse image under the injective map `g`.

The proof also handles the empty-codomain case separately, so the final theorem
has no inhabited-type restriction.

## Interpretation

This matches the classical Cantor-Schroeder-Bernstein theorem: mutual
embeddability of two sets implies equipotence. In Acorn, the statement is
expressed directly with injective and bijective functions between arbitrary
types.
