# #11 The Infinitude of Primes

Status: passed.

## Formalization

This is a complete Acorn wrapper proof for the standard Euclidean formulation of
infinitely many primes: for every natural number `n`, there exists a prime
natural number `p` with `n < p`.

The proof reuses the official standard-library theorem
`nat.nat_base.exists_infinite_primes`.

## Verification

- Acorn: `0.1.72`
- Verification: `1/1 OK`

## Acorn proof

```acorn
from nat import Nat
from nat.nat_base import exists_infinite_primes

/// Freek Top 100 #11: there are infinitely many primes.
theorem top100_011_infinitude_of_primes(n: Nat) {
    exists(p: Nat) {
        n < p and p.is_prime
    }
} by {
    exists_infinite_primes(n)
}
```
