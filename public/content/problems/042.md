## Formalization

This is a complete Acorn proof of the finite identity

```text
sum_{k=1}^n 1/T_k = 2n/(n + 1),
```

where `T_k = k(k + 1)/2`.

The Acorn development defines `triangular_term(k)` as the reciprocal of
`T_{k+1}` and `triangular_reciprocal_sum(n)` as the recursive sum of the first
`n` terms. The proof first rewrites each triangular reciprocal as an adjacent
reciprocal difference, then proves the finite telescoping identity by induction
on `n`, and finally converts the telescoped form into `2n/(n + 1)`.

The final public theorem is:

```acorn
theorem top100_042_triangular_reciprocal_sum(n: Nat) {
    triangular_reciprocal_sum(n) = ((Real.1 + Real.1) * from_nat[Real](n)) / from_nat[Real](n.suc)
} by {
    finite_telescoping_partial_sum(n)
    telescoping_closed_form_algebra(n)
}
```

## Interpretation

This matches the usual theorem that the sum of the reciprocals of the first
`n` triangular numbers is `2n/(n + 1)`.
