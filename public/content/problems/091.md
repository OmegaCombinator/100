## Formalization

This is a complete Acorn proof of the Euclidean triangle inequality on `R^2`.
The proof uses `Point2[Real]` and the concrete squared coordinate norm
`p.norm_sq`. Since the library does not currently expose a square-root-valued
Euclidean norm, the statement represents `r = ||p||` by saying that `r` is
nonnegative and `r * r = p.norm_sq`.

The final public theorem is:

```acorn
theorem top100_091_triangle_inequality_r2(
    a: Point2[Real], b: Point2[Real], an: Real, bn: Real, abn: Real
) {
    point2_real_norm(a, an) and point2_real_norm(b, bn) and point2_real_norm(a.add(b), abn)
        implies abn <= an + bn
}
```

The proof uses the existing finite real Cauchy-Schwarz theorem for the two
coordinate sequences, expands `Point2` squared norms, and then compares
nonnegative square roots.

## Interpretation

This matches the usual triangle inequality `||a + b|| <= ||a|| + ||b||` for
vectors in the real coordinate plane.
