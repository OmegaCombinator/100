# #1 The Irrationality of the Square Root of 2

Status: passed.

## Formalization

This is a complete Acorn proof of the rational-number version of the theorem:

```acorn
theorem top100_001_sqrt2_irrational_core(r: Rat) { r * r != Rat.2 }
```

The proof uses the standard infinite-descent argument in an integer-divisibility form. If `r * r = Rat.2`, Acorn rewrites this to the integer equation

```acorn
r.num * r.num = (Int.1 + Int.1) * (r.denom * r.denom)
```

Then it proves that both `r.num` and `r.denom` are divisible by `2`, contradicting the standard-library reducedness fact for rational numerator and denominator.
