## Formalization

This is a complete Acorn proof of the finite real Cauchy-Schwarz inequality in
squared form. The proof defines a finite dot product and finite square-sum for
real sequences, then proves:

```acorn
theorem top100_078_cauchy_schwarz(a: Nat -> Real, b: Nat -> Real, n: Nat) {
    finite_dot(a, b, n) * finite_dot(a, b, n) <=
        finite_square_sum(a, n) * finite_square_sum(b, n)
}
```

The reusable standard-library theorem is:

```acorn
theorem finite_cauchy_schwarz(a: Nat -> Real, b: Nat -> Real, n: Nat) {
    finite_dot(a, b, n) * finite_dot(a, b, n) <=
        finite_square_sum(a, n) * finite_square_sum(b, n)
}
```

The proof uses Lagrange's identity in squared form. It introduces the square
terms `(a_i b_j - a_j b_i)^2`, proves their rectangular finite sum is
nonnegative, and rewrites that sum as twice the Cauchy-Schwarz gap.

## Interpretation

This matches the standard finite-dimensional real Cauchy-Schwarz inequality
without using square roots: the square of the dot product is bounded by the
product of the two sums of squares.
