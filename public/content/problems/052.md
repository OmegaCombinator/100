# #52 The Number of Subsets of a Set

## Formalization

This is a complete Acorn proof of the finite powerset theorem for a finite set
represented by a duplicate-free list. The generated list `subset_list(items)`
contains exactly the finite subsets of `FiniteSet.from_list(items)`, and the
finite powerset formed from that list has cardinality `2^items.length`.

The full Acorn source is long because the proof currently builds the powerset
list, its exact membership theorem, its length theorem, and its duplicate-free
property explicitly. The final public theorem is:

```acorn
theorem top100_052_number_of_subsets_of_a_finite_set[A](items: List[A]) {
    items.is_unique implies
    forall(s: FiniteSet[A]) {
        finite_powerset[A](items).contains(s) =
        s.subset_eq(FiniteSet.from_list[A](items))
    } and
    finite_powerset[A](items).cardinality_is(Nat.2.pow(items.length))
} by {
    finite_powerset_exact[A](items)
    finite_powerset_cardinality[A](items)
}
```

Here `finite_powerset[A](items)` is the finite set built from `subset_list[A](items)`.
The upstream PR uses the underlying `fs_from_list[FiniteSet[A]]` helper for this
definition so certificate replay remains stable under `check --strict`.

## Interpretation

This matches the usual theorem that a finite set with `n` elements has exactly
`2^n` subsets. The Acorn statement also records the stronger extensional fact
that the generated powerset contains precisely those finite subsets, not just
the cardinality result.

The proof has been verified with Acorn.
