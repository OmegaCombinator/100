## Formalization

This is a complete Acorn proof of the factor and remainder theorems for real
coefficient polynomials represented by finite coefficient prefixes. A coefficient
function `c: Nat -> Real` and a bound `n` represent the polynomial using the
first `n` coefficients.

Evaluation is defined recursively by:

```acorn
define coeff_eval(c: Nat -> Real, x: Real, n: Nat) -> Real {
    match n {
        Nat.zero {
            Real.0
        }
        Nat.suc(pred) {
            c(Nat.0) + x * coeff_eval(coeff_tail(c), x, pred)
        }
    }
}
```

The remainder theorem is:

```acorn
theorem top100_089_remainder_theorem(c: Nat -> Real, a: Real, x: Real, n: Nat) {
    coeff_eval(c, x, n) = coeff_eval(c, a, n) + (x - a) * coeff_eval(coeff_quotient(c, a, n), x, n)
}
```

The factor theorem is stated as divisibility by the linear factor `X - a`:

```acorn
theorem top100_089_factor_theorem(c: Nat -> Real, a: Real, n: Nat) {
    coeff_eval(c, a, n) = Real.0 = coeff_divisible_by_x_minus_a(c, a, n)
}
```

where `coeff_divisible_by_x_minus_a(c, a, n)` means that there exists a
coefficient polynomial `q` such that, for all real `x`,
`c(x) = q(x) * (x - a)` under the bounded coefficient evaluation.

## Interpretation

This matches the classical statements: division by `X - a` leaves remainder
`f(a)`, and `a` is a root of `f` exactly when `X - a` is a factor of `f`.
