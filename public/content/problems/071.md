## Formalization

This is a complete Acorn proof of Lagrange's theorem for finite groups: the
order of any finite subgroup divides the order of the ambient finite group.

The proof builds the standard left-coset argument explicitly. It defines the
left coset associated to a representative, proves that representative cosets
cover the whole finite group, proves distinct representatives give disjoint
cosets, proves each coset has cardinality `s.order`, and then turns the finite
disjoint union into the product formula

```acorn
s.order * finite_left_coset_representatives[G](s).length = G.order
```

The final public theorem is:

```acorn
theorem top100_071_lagrange_theorem[G: FiniteGroup](s: FiniteSubgroup[G]) {
    s.order.divides(G.order)
} by {
    let reps_len: Nat = finite_left_coset_representatives[G](s).length
    divides_self(s.order)
    divides_mul(s.order, s.order, reps_len)
    finite_left_coset_representatives_order_product_eq_group_order[G](s)
}
```

## Interpretation

This matches the usual statement of Lagrange's theorem: if `H` is a subgroup of
a finite group `G`, then `|H|` divides `|G|`.
