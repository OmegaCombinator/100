# #44 The Binomial Theorem

Status: passed.

## Formalization

This is a complete Acorn wrapper proof for the Top 100 binomial theorem target over commutative rings. It uses the current official standard-library theorem `comm_ring.binomial.binomial`, whose statement proves:

```acorn
(a + b).pow(n) = partial(binomial_term[R](a, b, n), n.suc)
```

for any commutative ring `R`, elements `a b : R`, and `n : Nat`.

## Acorn proof

```acorn
from comm_ring.base import CommRing
from comm_ring.binomial import binomial, binomial_term
from list import partial
from nat import Nat

/// Freek Top 100 #44: the binomial theorem for commutative rings.
theorem top100_044_binomial_theorem[R: CommRing](a: R, b: R, n: Nat) {
    (a + b).pow(n) = partial(binomial_term[R](a, b, n), n.suc)
} by {
    binomial[R](a, b, n)
}
```
